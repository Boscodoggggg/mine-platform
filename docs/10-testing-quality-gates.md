# 10 测试体系与上线质量门禁

## 1. 原则

测试的目标不是获得漂亮覆盖率，而是证明：

- 报文在边界和异常情况下仍能正确解析。
- 重复、乱序和补传不会破坏数据和业务状态。
- RabbitMQ、数据库和服务重启后链路可恢复。
- 权限、危险命令和策略发布不能绕过保护。
- 单机/多机安装、升级、备份和回滚真的可执行。

## 2. 测试分层

### 2.1 单元测试

必须覆盖：

- CRC、校验和、转义、大小端和位域。
- 定长、长度字段、分隔符、TLV、半包、粘包。
- scale、offset、enum、单位和质量映射。
- 策略继承、冲突和有效配置。
- 命令状态机、TTL、重试和幂等。
- 迟到、乱序、sequence gap、bootId 变化。
- 围栏进入/离开、抖动消除和作业状态。

核心协议/策略/命令/弱网分支覆盖率目标不低于 90%；业务 Service 不低于 80%。DTO、简单 getter 和框架配置不为追求数字写无价值测试。

### 2.2 协议黄金样本

每个协议版本的样本目录：

~~~text
examples/protocols/{protocolKey}/{version}/
├── manifest.yaml
├── valid/
├── invalid-crc/
├── partial/
├── sticky/
├── boundary/
├── unknown/
└── commands/
~~~

manifest 描述输入格式、期望消息、期望错误和适用物模型。发布和 CI 使用同一回放引擎。

### 2.3 Spring 切片

- @WebMvcTest/MockMvc：参数、错误结构和 Sa-Token 权限。
- Mapper/Repository：真实 PostgreSQL 容器和 migration。
- JSON schema：兼容性和未知字段。
- Rabbit producer/consumer：序列化、路由和重试策略。

### 2.4 集成测试

Testcontainers 启动：

- RabbitMQ 并启用 MQTT 插件。
- PostgreSQL/TimescaleDB。
- Redis。
- 必要的 S3 兼容测试服务。

禁止用 H2、内存假 MQ 证明生产集成正确。

### 2.5 端到端

上行：

~~~text
MQTT发布
→ RabbitMQ MQTT
→ gateway
→ /mine-platform
→ telemetry
→ TimescaleDB/Redis
→ WebSocket
→ 浏览器断言
~~~

下行：

~~~text
浏览器创建命令
→ server/outbox
→ RabbitMQ
→ gateway
→ MQTT设备模拟器
→ 设备ACK
→ 命令状态时间线
~~~

### 2.6 现场系统测试

- 单机离线安装。
- 五节点部署和滚动升级。
- 主备切换。
- 备份恢复。
- 断电/重启后恢复。
- 真实设备长时间运行。

### 2.7 告警闭环自动化基线

告警切片的非现场门禁至少覆盖：

- 共享策略注册表：双来源字段矩阵、数量/精度/时间边界、迟滞、未知字段和原子覆盖。
- 持久状态机：即时/持续触发、抖动、恢复持续、迟滞、冷却、缺值保持、质量规则命中、乱序和策略变更恢复。
- 事务与可靠消息：状态、遥测事实和 Outbox 原子提交，精确重试、publisher confirm、启动有界恢复及死信。
- Server 聚合：Inbox 幂等、恢复早到、触发晚到、冲突拒绝、首次确认、恢复后关闭、乐观锁、审计和中文数据库注释。
- 前端：规则编辑/复制/排序、原子覆盖提示、有效策略、默认未关闭查询、筛选、详情、权限、幂等重试与 `409` 刷新。
- 部署：quorum 队列、死信、最小 RabbitMQ 账号权限、Compose secret、低基数指标和 Prometheus 规则。

这些测试可以证明仓库契约和容器集成基线，不能替代真实设备阈值、通知送达、矿区网络、容量、HA、备份恢复、故障演练或 24/72 小时长稳。

### 2.8 数据保留闭环自动化基线

数据保留切片的非现场门禁至少覆盖：

- 共享策略契约：原子 `policy`、四个等级边界、未知/缺失字段、整数约束和质量证据期限倒挂。
- 可靠镜像：不可变运行快照、分页完整性、低修订、同修订异内容、损坏快照和最后正确值保护。
- 数据库执行：单实例锁竞争、禁用跳过、数据库时间、全局最短期限预过滤、每设备期限、`received_at` 保护、有界批次、失败回滚、重试和失联执行恢复。
- 数据边界：只清理原始数值遥测和质量证据，Inbox、最新值、告警状态/Outbox、策略水位和执行终态保持不变。
- 只读管理面：已保存版本、发布后逐设备最终覆盖、禁用短路、100 万行统计上限、统计时点、一次性凭证、内容/作用域/成员变化失效、执行历史、不可用降级和权限；设备组成员、优先级、归档间接激活覆盖回退、权限撤销、过期、复用和事务回滚。
- 前端与导航：四个预设、未保存修改阻断、发布/回滚分别预览并提交凭证、不可逆提示、执行事实、独立菜单、固定 `RETENTION`、中英文、主题治理和精确非级联 RBAC。
- 部署：默认关闭/Compose 显式开启、参数边界、单线程固定延迟、低基数指标、三条 Prometheus 告警和配置回归。

自动化通过不等于允许在生产数据上执行清理。真实数据 dry-run、备份恢复、容量/WAL、HA、长稳和变更窗口仍是现场正式上线的阻断门禁。

### 2.9 数值聚合闭环自动化基线

数值聚合切片的非现场门禁至少覆盖：

- 共享策略契约：原子 `policy`、固定桶白名单、规则数量/属性格式/去重、修正窗口、未知字段和自由表达式拒绝。
- 可靠镜像：不可变运行快照、分页完整性、共享定义复验、暂存、原子激活、低修订、同修订异内容和最后正确值保护。
- 常规物化：数据库 advisory lock、固定源摄取水位、UTC 闭合桶、修正窗口、窗口内迟到、超窗口迟到计数、有界批次、`PARTIAL`、失败回滚、脱敏和失联恢复。
- 版本事实与查询：AVG/MIN/MAX/样本数/最差质量/最晚接收、策略证据、追加版本、原始/rollup 双水位、冷热边界和后台重算期间分页稳定。
- 数据保留门禁：有规则属性的覆盖缺失、失败版本和修正窗口内原始数据不得清理；成功覆盖后才允许删除；无规则属性保持原行为。
- 显式重算：精确规则、权限、幂等、审计、31 天/10000 桶上限、`FOR UPDATE SKIP LOCKED`、租约转移、稳定 executionId、旧 token 拒绝、固定源水位、超窗口迟到纳入、版本追加和终态重放。
- 前端与部署：动态聚合菜单、工作台、执行事实、重算二次确认、精确 RBAC、中英文、主题治理、默认关闭/Compose 显式开启、低基数指标和 Prometheus 规则。

自动化通过不等于真实矿区聚合容量或查询性能达标。真实数据分布、弱网迟到、WAL/IO、并发查询、批量重算、HA、备份恢复和 24/72 小时长稳仍是现场正式上线的阻断门禁。

## 3. 前端测试

Vitest + Vue Test Utils：

- 主题 token、主题模式唯一来源和业务页面无硬编码颜色。
- 中英文资源完整性、语言切换和用户可见文案无硬编码。
- 动态物模型组件。
- 策略继承来源和冲突。
- 权限路由/按钮。
- 协议样本差异。
- 命令二次确认和状态。
- RealtimeHub 重连、订阅引用计数、批量通知。
- 告警规则来源切换、精度/迟滞、复制排序、原子覆盖提示、告警详情和处置幂等。
- 数据保留预设、等级边界、已保存版本精确预览、脏表单阻断、回滚重预览、一次性凭证、执行历史、不可逆提示、独立导航和只读依赖授权。
- 数值聚合固定桶规则、修正窗口、重复规则、有效值、运行事实、显式重算权限/二次确认、租约状态和稳定错误展示。

Playwright：

1. 超级管理员登录和修改初始密码。
2. 创建角色并分配菜单/按钮。
3. 创建产品、设备和凭据。
4. 导入/编辑协议样本并发布。
5. 发布/回滚配置包。
6. 设备上线、实时值和历史曲线。
7. 命令下发、设备拒绝和超时。
8. 告警默认未关闭视图、恢复未确认、确认幂等与恢复后关闭。
9. UWB 轨迹和三维 demo smoke test。
10. 从“数据治理 → 数据保留”进入固定策略页，完成影响预览、风险确认和发布闭环。
11. 从动态“数据治理 → 数值聚合”进入治理页，查看执行事实并登记有界重算。

测试通过可访问性角色和文本查询元素，不依赖脆弱 CSS 层级。

## 4. 数据库测试

- 所有 Flyway migration 从空库执行。
- 从上一正式版本升级执行。
- migration 幂等边界和失败恢复。
- 时序 hypertable、索引和保留任务。
- 保留策略镜像、执行事实和预览凭证全部中文注释；覆盖终态保护、一次性激活、V27→V29 升级与 UUIDv7 关联。
- 聚合策略镜像、版本化 rollup、常规/重算执行事实和控制面租约全部中文注释；覆盖 V30～V32、Telemetry V17～V20、双水位、不可变触发器、租约恢复和稳定执行标识。
- 大批量插入和查询计划。
- 绑定有效期不重叠约束。
- outbox/inbox 幂等。
- 备份与同版本/目标版本恢复。

## 5. MQTT/协议测试矩阵

| 场景 | 期望 |
|---|---|
| 正常 QoS 0/1 | 正确解析和入库 |
| 重复 QoS 1 | 只产生一次业务副作用 |
| clientId 冲突 | 按策略拒绝/替换并告警 |
| 错误凭据 | 拒绝且指标增加 |
| 越权 topic | 拒绝发布/订阅 |
| 半包/粘包 | 正确组帧 |
| 超长帧 | 立即拒绝，连接按策略关闭 |
| CRC 错误 | 不进入正常遥测，保留错误上下文 |
| 未知消息 | 进入未知类型指标/样本收集 |
| 设备重启 | bootId 切换，sequence 新周期 |
| 迟到补传 | 写历史，不覆盖最新值 |
| 下行无业务 ACK | 命令最终超时，而非成功 |

## 6. 性能模型

至少包含：

- 5000 个并发 MQTT 客户端。
- 正常稳态连接。
- 分批和同时重连风暴。
- 遥测不同报文大小和频率。
- UWB 高频位置点。
- QoS 0/1 混合。
- 设备订阅下行。
- 100 个管理端 WebSocket（具体按现场调整）。
- 协议解析成功/失败混合。
- RabbitMQ 积压后恢复。

报告必须输出：

- 连接成功率和重连时间。
- 每秒消息、端到端 P50/P95/P99。
- 解析耗时。
- RabbitMQ ready/unacked/confirm。
- Timescale 写入速率和批次延迟。
- CPU、内存、GC、磁盘 IO、网络。
- WebSocket 推送延迟和浏览器帧率。
- 丢弃、重试、重复和 DLQ 数。

## 7. 弱网与故障注入

网络注入：

- 延迟、抖动、限速。
- 随机丢包。
- 重复、乱序。
- 1 分钟、10 分钟、1 小时断网。

组件故障：

- gateway/telemetry/server kill -9。
- RabbitMQ 单节点停止。
- 数据库主库停止。
- Redis 主节点停止。
- 对象存储不可用。
- 磁盘接近满。
- 时间偏差和证书过期。

验证点：

- 是否自动恢复。
- 是否产生数据缺口。
- 是否重复产生告警/作业。
- 队列是否有界。
- 运维告警是否及时且可理解。

## 8. 72 小时稳定性

条件：

- 使用接近预计峰值的持续负载。
- 每天至少一次设备批量重连。
- 执行配置热发布/回滚。
- 执行命令和告警链路。
- 注入一次应用实例重启。

通过标准：

- 无持续内存增长和线程泄漏。
- 无不可恢复消费停滞。
- 无数据库连接池耗尽。
- 无 RabbitMQ 无界积压。
- 无重复业务副作用。
- 指标、日志和审计完整。
- 数据量和磁盘增长符合模型。

## 9. 安全测试

- 越权 API、按钮隐藏绕过。
- MQTT topic ACL。
- 登录爆破和限流。
- token 注销/踢下线。
- 上传路径穿越、超大文件和伪造 MIME。
- 协议配置超大正则/字段越界。
- JSON 深度和消息大小。
- 命令幂等和危险命令离线。
- secret/log 脱敏。
- 依赖与镜像漏洞扫描。

## 10. 发布门禁

每次合并：

- 编译、格式、静态检查。
- 单元和架构测试。
- 前端主题与国际化治理检查、typecheck、lint、unit 和生产构建。
- migration 校验。
- 协议黄金样本 100% 通过。

候选版本：

- Testcontainers 集成。
- Playwright 核心旅程。
- SBOM、许可证和漏洞门禁。
- 镜像构建和离线安装 smoke test。

现场正式上线：

- 5000 客户端容量测试。
- 弱网补传。
- 故障演练。
- 72 小时稳定性。
- 备份恢复。
- 升级回滚。
- 安全检查。
- 上线清单签字。

任何核心样本失败、严重漏洞、不可恢复丢数或备份未验证都阻止发布。

## 11. 测试数据

- 模拟数据不使用真实人员隐私和生产凭据。
- 真实报文进入测试库前脱敏。
- 协议样本保留来源、设备型号和期望版本。
- 随机测试必须可重放，记录 seed。
- 性能测试结果绑定代码版本、配置包版本和硬件清单。
