# 实施计划索引

## 使用方法

plans/ 是面向 Codex 的任务执行手册。执行任何计划前：

1. 把本设计文档集复制到正式仓库 docs/。
2. 读取根 AGENTS.md。
3. 确认正式仓库地址；Maven groupId 已固定为 `com.bosco`，Java 基础包已固定为 `com.bosco.mine`，许可证已固定为 Apache-2.0。
4. 创建独立功能分支或工作树。
5. 严格按测试先行、最小实现、验证、中文提交执行。

## 每项任务的结束条件

- 失败测试先出现，并确认因缺少目标行为失败。
- 最小实现通过针对测试。
- 当前模块全量测试通过。
- 契约、migration、指标、权限和文档同步。
- git diff 无无关变更。
- 中文 Conventional Commit。
