# 设备接入方式动态表单设计

## 目标

设备接入抽屉在 MQTT、设备主动 TCP 和平台主动 TCP 之间切换时，应展示符合当前连接方向的字段名称、说明、占位文案和默认值，避免把平台地址与设备地址混淆。

## 交互设计

- MQTT：`host/port` 表示平台 Broker 地址和端口，默认使用 8883、TLS 开启、MQTT KeepAlive 60 秒。
- 设备主动 TCP：`host/port` 表示现场设备应连接的平台 TCP 监听地址和端口，默认端口 9000、TLS 关闭、应用心跳 60 秒。
- 平台主动 TCP：`host/port` 表示设备或边缘网关地址和端口，默认端口 9000、TLS 关闭、应用心跳 60 秒；`connectTimeoutMillis` 表示连接设备超时。
- 每种模式维护独立的未保存草稿。切换时先记录当前模式，再恢复目标模式草稿；首次切换则使用目标模式默认值。
- 切换模式后保持“需先保存才可测试”的安全边界。

## 边界

本次复用现有连接配置契约，不新增数据库字段。设备主动 TCP 暂以可编辑的平台监听地址表达；未来建立统一 TCP 监听器资源后，再替换为受控选择器。
